Joybuy (en ligne)

vide

Joybuy n'a pas de base de prix publique et bloque les robots. Les prix, notes et avis sont donc lus depuis ton navigateur sur joybuy.fr, avec ton favori « Chef Joybuy » (30 recherches ≈ 30 secondes). Les prix restent valables 3 jours.

Installer le favori « Chef Joybuy » (une seule fois)
  1. Copie le code du favori ci-dessous.
  2. Dans ton navigateur, ajoute n'importe quelle page en favori, puis modifie ce favori : nom Chef Joybuy, adresse = colle le code.
  3. Connecte-toi à ton compte sur joybuy.fr dans ce même navigateur.
  4. Ensuite, quand Chef de Poche ouvre Joybuy : Android (Chrome) tape « Chef Joybuy » dans la barre d'adresse et touche le favori proposé ; iPhone (Safari) ouvre les favoris et touche « Chef Joybuy » ; ordinateur clique le favori dans la barre.

Utilise Chef de Poche dans le même navigateur que Joybuy (Chrome sur Android, Safari sur iPhone) : l'icône installée sur l'écran d'accueil de l'iPhone garde des données séparées. Si le retour automatique ne marche pas, touche « Copier les résultats » sur Joybuy puis « Coller les résultats » ici.
